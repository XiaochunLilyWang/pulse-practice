# PULSE · 四键节奏练习器

一个为手机竖屏设计的 4K 下落式音游练习器。自由设置 BPM、节奏、键型、下落速度和练习长度，把注意力放在节奏与手感上。

**[在线体验](https://xiaochunlilywang.github.io/pulse-practice/)** · **[小红书上传包](releases/pulse-practice-xhs-tool.zip)** · **[模拟演示视频](releases/PULSE-120BPM-6.5-十六分随机-100模拟.mp4)**

## 功能

- **BPM**：30–300，支持输入、滑条和加减按钮。
- **节奏型**：四分音符、八分音符、三连音、十六分音符及自定义节奏；固定 4/4 拍。
- **自定义节奏**：在一小节内点击或拖动绘制／擦除音符；留空代表休止。支持 1/16（每拍 4 格）和 1/12（每拍 3 格）精度，分别保存编辑结果。① 是每拍的起点。
- **键型**：纵连、交互、楼梯、随机。纵连与交互可分别选择固定轨道或每小节换轨；预设三连音的楼梯为 `1→2→3 / 2→3→4` 两组交替。
- **下落速度**：1–10 档，步长 0.5，只改变视觉速度，不改变 BPM。5 档到达判定线约 850ms，6.5 档约 670ms。
- **练习长度**：1–128 小节，附带 4／8／16／32 小节快捷选择。
- **声音反馈**：可开关的节拍器，以及独立的命中打击音；关闭节拍器不影响打击音。开始前保留四拍倒数提示音。
- **练习反馈**：实时准确率、连击、小节进度、偏早／偏晚；结束后显示最大连击和各项判定数量。
- **其他**：实时谱面预览、暂停、重练、切到后台自动暂停、本地保存练习设置。

## 如何练习

1. 设置 BPM、节奏型、键型、速度和小节数。
2. 点击“开始练习”，跟随四拍倒数准备。
3. 音符到达底部判定线时，点击对应轨道。
4. 结束后查看成绩，直接重练或调整参数。

手机支持多指点击四条轨道。电脑使用 **D / F / J / K**，**空格**暂停或继续。

### 判定与准确率

| 判定 | 与目标时间的绝对偏差 | 准确率权重 |
| --- | --- | --- |
| PERFECT | ≤ 50ms | 100% |
| GREAT | > 50ms 且 ≤ 100ms | 50% |
| LOST | 超过命中窗口未击中／漏击 | 0% |

准确率 = `(PERFECT 数 + GREAT 数 × 0.5) ÷ 已判定音符数 × 100%`。结算时以全部音符为分母。LOST 会打断连击；空击不计分，也不播放命中音。

固定纵连使用第 1 轨，固定交互使用第 1、4 轨。每小节换轨模式在小节边界切换，适用于预设及自定义节奏。

## 本地运行

游戏不依赖 npm 包、后端服务或在线资源。克隆后，使用 Python 3 启动静态服务器：

```sh
git clone https://github.com/XiaochunLilyWang/pulse-practice.git
cd pulse-practice
python3 -m http.server 4173
```

访问 <http://localhost:4173/>。同一局域网中的手机也可以使用电脑的局域网 IP 和对应端口打开。

## 小红书小工具打包

构建与校验需要 **Python 3.10+ 和 Node.js 18+**，均不需要额外安装第三方包。

```sh
python3 scripts/build_xhs.py
python3 scripts/check_xhs.py
node scripts/test_hitsound.cjs
```

输出：

- `xhs-dist/`：平台适配后的离线静态文件。
- `releases/pulse-practice-xhs-tool.zip`：小红书上传包，根目录直接包含 `index.html`、`app.js` 和 `style.css`。

构建脚本将内联脚本拆为经典外置脚本，并针对 ES2017 / Chrome 61 补齐数组方法、布局间距、安全区等适配。音效通过 Web Audio 本地合成，无需音频文件或麦克风权限。

平台适配依据小红书提供的 [minitool-zip-builder 1.6.0 skill](https://fe-static.xhscdn.com/mini-tool/20260831163932/minitool-zip-builder-1.6.0.skill)。该 skill 不包含在此仓库中；如需重新执行其官方体积审计，请单独下载并按指引运行。

**上传后请使用小红书真机预览确认声音、触控、判定延迟及安全区，再发布。** 静态校验不代表平台审核通过。

## 当前边界

- 当前为单点音符练习，尚无长按、和弦、歌曲导入和音频延迟校准。
- 随机键型采用可复现序列，相同配置可以反复练习同一谱面。
- 设置保存在浏览器本地；清理数据、切换浏览器或容器可能导致设置丢失。
- 真机音频与触控延迟、Chrome 61、小红书容器性能尚未完成实测。蓝牙耳机等设备的延迟可能影响手感。
- 已有静态校验、音效逻辑测试，以及现代浏览器中的基础流程检查；模拟录屏并非真机性能验证。
